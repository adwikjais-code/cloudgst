# GSTR-2B + TCS fetch — step by step (aapke 6 screenshots ke hisaab se)

Bridge **v1.26.0** · App/web bundle me **koi change nahi** (v5_8_2 hi chalega)

---

## Step 1 — Login (screenshot 1)
`services.gst.gov.in` → client ID + password + captcha → **User Dashboard** (Welcome Busara bano…).
*App karta hai:* bridge login (captcha wala). Dashboard khulne par aage badhta hai.

## Step 2 — Services → Returns → Returns Dashboard (screenshot 2)
Menu: `Services ▾ → Returns → Returns Dashboard`.
*App karta hai:* `RETURN DASHBOARD` button/link dhundh kar click; na mile to seedha URL
`…/services/returns/auth/dashboard`.

> ⚠️ Portal kabhi-kabhi wapas **User Dashboard** par phenk deta hai. Pehle yahan "FY:true / Month:false" error aata tha.
> **Ab:** month dropdown na dikhe to app URL se Returns Dashboard **dobara kholta hai**, phir reload karke retry karta hai.

## Step 3 — File Returns: FY / Quarter / Period + SEARCH (screenshot 3)
`Financial Year 2026-27` · `Quarter 3 (Oct – Dec)` · `Period November` → **SEARCH**.
*App karta hai:* FY + Period (month) select, Quarter agar ho to, phir SEARCH.
**Month hi asli period hai** — FY+Month match hone par hi aage badhta hai (galat period ka data kabhi nahi uthata).

## Step 4 — Tiles: GSTR-2B card → DOWNLOAD (screenshot 4)
Tiles: GSTR-1 (VIEW/DOWNLOAD) · Amendment · **Auto-drafted ITC Statement GSTR-2B (VIEW | DOWNLOAD)** · GSTR-3B · GSTR-2A.
*App karta hai:* 2B card ka **DOWNLOAD** dabata hai.

## Step 5 — Offline Download page: GENERATE JSON (screenshot 5)
`gstr2b.gst.gov.in` → **Offline Download for GSTR-2B** → buttons:
`GENERATE JSON FILE TO DOWNLOAD` · `GENERATE EXCEL FILE TO DOWNLOAD`.
*App karta hai:* **GENERATE JSON FILE TO DOWNLOAD** dabata hai (yahan download link hota hi nahi — generate hi karna padta hai).

- **2B bani hui** → click ke **turant** file download → parse → **✓ Synced** (₹ figures + TCS)
- **2B nahi bani** → upar **red error banner turant** (screenshot 6) → app **`not generated`** likh kar turant aage

## Step 6 — 2B nahi bani (screenshot 6)
Banner (26-Nov wording bhi ab detect hota hai):
> *"Error! Either there is no record for GSTR 2B or GSTR 2B for current return period is not generated by system
> (due to non-filing GSTR 3B of last return period …), kindly go to IMS dashboard, and compute your GSTR 2B manually."*

*App karta hai:* **turant `2B not generated`** (row me chhota grey italic), phir **TCS section** par aage — **90s wait nahi**.
Purani wording (`could not be generated by the System`, `no records to generate GSTR 2B`, `will not generate GSTR 2B`, `has not been generated`) bhi detect hoti hai.

## Step 7 — E-Com / TCS
`Services → Returns → TDS and TCS credit received` → FY/Period → SEARCH → **PREPARE ONLINE** (ya VIEW) →
`TCS Credit Received – Summary` → rows padhta hai (ACCEPT/REJECT **kabhi nahi** dabata).
*App karta hai:* agar hum returns dashboard par nahi hain to pehle dashboard kholta hai, phir PREPARE ONLINE
**button aane tak** wait (1s steps, max 12s — pehle jaldi chhoot jata tha), uske baad summary.

## Step 8 — Save
Sheet me columns (`GSTR2B_*`, `ECom_*`, `GSTR2B_Status`) + Drive me 2B JSON (agar option ON) + app row me status.

---

## Timing (jaldi wala behaviour)
| Situation | Time |
|---|---|
| 2B bani hui (generate → download) | **1–3 s** |
| 2B nahi bani (error banner) | **1–3 s** → `not generated` |
| Generate ke baad kuch bhi na aaye | max **10 s** → `not generated` |
| 2B card / DOWNLOAD hi na mile | turant (page text se decide) |
| PREPARE ONLINE button | milte hi aage, max 12 s |
| TCS summary | "number of records" aate hi, max 6 s |

## Fail hone par
Kuch bhi samajh na aaye to error line me `gstr2b_*` / `tcs_*` debug keys aati hain
(`gstr2bOfflinePageText`, `gstr2bAfterDownload`, `tcsCardsExcerpt`, `tcsTcsPageExcerpt`) — wahi bhej dijiye,
usse pata chal jayega portal ne kaunsa page diya.
