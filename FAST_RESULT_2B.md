# GSTR-2B na mile to turant aage — "not generated" (bridge v1.23.0)

## Asli rukavat kahan thi (v1.22.0 me bachi hui)
Aapke screenshot wale page par **GENERATE JSON button hota hi nahi** (error page hai). Purana code wahan
seedha `"GSTR-2B GENERATE JSON button nahi mila"` likh deta tha — na 90s ka loop chalta, na label aata,
aur 2B "failed" dikhta tha, "not generated" nahi.

**Ab:** button na milne par **pehle page ka text padha jata hai**:
- `Error! GSTR-2B could not be generated by the System` → **`not generated`** (turant, ~2-3 second me)
- `Session expired / please login again` → saaf message
- kuch aur → purana generic message

## Ab 4 jagah 2B ka "not generated" pakda jata hai
| Kahan | Kab |
|---|---|
| Returns dashboard khulte hi | page par error text |
| 2B card / DOWNLOAD button na mile | page par error text |
| **GENERATE JSON button na mile** | **naya — aapka case** |
| Generate ke baad polling (har 3s) | error text dikhte hi break (90s nahi) |

Delete/na-milne wale case me workflow **turant aage badh jata hai** (E-Com / TCS section chalta rehta hai),
aur result me 2B ka status `code: "gstr2b_not_generated"` chala jata hai → row me chhota **`not generated`**.

## False positive se bachav
Broad line (`will not generate GSTR 2B`) tabhi maani jati hai jab page par `Error`/`Attention` bhi ho —
normal page ke disclaimer par galti se "not generated" nahi likhega. (`gstr2bPageSaysNotGenerated()`)
